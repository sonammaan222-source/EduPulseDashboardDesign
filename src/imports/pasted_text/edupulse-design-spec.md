UI/UX Requirements
Every navigation item, button, card, and image should be clickable.
Use Auto Layout and reusable components throughout.
Design dedicated pages for each major section.
Add hover effects, active navigation states, page transitions, loading skeletons, and smooth micro-interactions.
Use a 12-column responsive grid with desktop, tablet, and mobile variants.
Include placeholders for dynamic content so news and exam information can be updated easily without redesigning the interface.

Goal: Create a portfolio-quality UI that looks like a professional national education news platform, combining the credibility of a newspaper with the usability of a modern analytics dashboard. It should be visually striking, easy to navigate, and suitable for showcasing frontend UI/UX design skills.
